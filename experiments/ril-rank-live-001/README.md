# RIL-RANK-LIVE-001 — matched live-agent transfer of the frozen ranking signal

RIL-RANK-EXEC-001 established a controlled executable result: the exact frozen RIL-RANK-001 evidence-derived ordering found acceptable receiver-executed improvements more often than both controls under a four-evaluation budget. It did **not** test a live researcher.

RIL-RANK-LIVE-001 is the smallest live successor. Sixteen fresh executable microtasks are generated after the candidate orders are durably sealed. Each task has the same 12-candidate pool in both arms, the same frozen receiver history, the same Hermes researcher, the same model, and the same resource limits. Only the candidate ordering differs: one arm uses the inherited evidence ranker and the other uses the frozen baseline order.

The live researcher sees the complete pool but may only reorder the first four budget-eligible candidates. The receiver then executes those four deterministic candidate implementations in the researcher's returned order and stops at the first candidate that clears the frozen correctness-and-efficiency objective. This makes the live agent a bounded researcher, not the evaluator and not the source of truth.

A pass requires all live calls and cost telemetry to be valid, at least a 12.5-point confirmed-improvement-rate advantage over baseline, fewer downstream receiver evaluations, and higher confirmed improvements per live-model dollar. Model spend and receiver-evaluation savings are reported separately. The inherited 768-evaluation learning cost remains carried forward and is not wished away.

Even a pass earns only **single-run matched live-agent selection transfer on these executable microtasks**. It does not establish repeatability, live coding productivity, Level 4 recursive improvement, recursive self-improvement, production value, universal transfer, or hostile-process isolation. The improved ordering policy was inherited from an earlier calibration; it was not generated and promoted by this live loop.

The paid primary is manual-only. Push the branch first so structural CI verifies the exact preregistration and predecessor binding. Then dispatch `RIL-RANK-LIVE-001 matched live transfer` once from the experiment branch.
