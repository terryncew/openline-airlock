# Maintbox

Maintbox is the fresh SEARCH-002 maintenance substrate.

The repository has a public scorecard at `.airlock/search-002/scorecard.json`. That file states exactly which outcomes matter. Agents may read it. They may not modify it.

The job is ordinary maintenance: find a small source change that improves one or more scored outcomes while keeping public checks green.

Some modules are merely ugly or old. Cosmetic cleanup earns nothing unless it improves a scored consequence.
